# Configurador de mapa de stakeholders

Aplicación web construida con Vue 3 + Vite y Tailwind CSS para diseñar, priorizar y visualizar mapas de stakeholders.

## Características

- Asistente en tres pasos para definir el contexto del proyecto, catalogar actores clave y visualizar el mapa final.
- Formulario guiado con soporte para hitos y enlaces de referencia.
- Clasificación de actores por nivel de influencia, interés y actitud.
- Mapa matricial de interés vs. influencia que resume la priorización.
- Botón de auto rellenado con datos de ejemplo para validar el flujo.

## Requisitos previos

- Node.js 18 o superior
- npm 9+ (incluido con Node)

## Instalación

```bash
npm install
```

## Scripts disponibles

| Comando        | Descripción                             |
| -------------- | --------------------------------------- |
| `npm run dev`  | Inicia el entorno de desarrollo con Vite |
| `npm run build`| Genera la build de producción            |
| `npm run preview` | Previsualiza la build generada       |

## Uso rápido

1. Ejecuta `npm run dev` y abre el navegador en `http://localhost:5173`.
2. Completa los pasos del asistente o pulsa **Auto rellenar demo** para cargar un caso de prueba basado en la planta desaladora de Níjar.
3. Revisa el mapa de interés vs. influencia y planifica las acciones de relacionamiento.
